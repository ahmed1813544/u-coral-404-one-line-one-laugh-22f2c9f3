## The line

> I finally used the good towels. My wife looked at me the way museums look at people who touch the paintings.

## How it works

`main.py` (Python 3, standard library only) writes exactly one funny line
to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`
(default `/output`).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
